# Miami Home Guide - starter site

This is a starter homepage for your Miami real estate lead-gen site.

## How to put this on GitHub (no coding commands needed)
1. Go to github.com and click the "+" icon top right, then "New repository."
2. Name it something like "miami-home-guide" and click "Create repository."
3. On the next page, click "uploading an existing file."
4. Drag every file and folder from this download into that upload box.
5. Click "Commit changes" at the bottom.

## How to connect it to Vercel
1. Go to vercel.com and click "Add New" -> "Project."
2. Choose "Import Git Repository" and pick the "miami-home-guide" repo you just made.
3. Leave all settings as default and click "Deploy."
4. In a minute or two, Vercel gives you a free live link to your site.
